# Admasker 랜딩 방향

## 핵심 메시지

- 광고주: **수많은 AI 영상에 여러분의 제품을 광고하세요.**
- AI 크리에이터: **여러분의 영상에 PPL을 추가하세요.**
- 공통 원칙: 스토리와 영상의 퀄리티를 지키면서 제품이 장면에 자연스럽게 녹아드는 광고.

## 화면과 진입 경로

1. 첫 화면은 역할별 메시지와 원본/PPL 시안 비교입니다. 인물 프로필과 크리에이터 검색을 랜딩에서 제거했습니다.
2. 광고주의 `제품 광고 시작하기`는 기존 `/campaigns?create=1` 광고 캠페인 등록 흐름으로 연결합니다.
3. AI 크리에이터의 `내 영상에 PPL 추가하기`는 기존 `/studio` 영상·제품 업로드로 연결합니다.
4. 장면 소개는 웹드라마·라이프스타일·패션의 광고 활용 예시입니다. 실제 영상 목록이나 재생 가능한 AI 영상으로 표시하지 않습니다.
5. 광고 캠페인은 실제 API 데이터를 사용하고, 없거나 연결에 실패하면 명확히 구분한 가상 예시를 제공합니다. 분야 필터와 재연결을 유지합니다.
6. 이용 방법과 FAQ는 제품 등록 → 장면 검토 → PPL 시안 확인, 영상 업로드 → 제품 배치 → 광고 수익 기회의 흐름으로 구성합니다. 자동 집행·결제·확정 수익을 약속하지 않습니다.

## 참고 범위

이전 버전에서 확인한 [Collabstr](https://collabstr.com/), [리뷰노트](https://www.reviewnote.co.kr/)는 캠페인 카드와 정보 구조의 참고입니다. 서비스의 주제는 AI 영상에 제품을 더하는 PPL 광고입니다.

## 현재 구현과 표현

- 비교 이미지는 콘셉트 사진과 가상 브랜드 morrow의 제품 배치 시안입니다. 실제 AI 재생성 결과나 집행 사례가 아닙니다.
- 등록 영상 수, 광고 집행 실적, 고객 로고, 자동 추천, 자동 게시, 지급 수익을 만들어 표시하지 않습니다.
- 현재 영상 스튜디오는 제품의 위치·크기·노출 구간을 설정하는 시안을 제공합니다. 실제 GPU 추론과 제품·로고 재현 품질은 아직 검증 전입니다.
- 공개 프로필·지원·선정은 광고 운영을 지원하는 기존 기능으로 유지합니다. 영상 인벤토리 API를 새로 만든 것으로 표현하지 않습니다.
