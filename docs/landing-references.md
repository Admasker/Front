# 랜딩 구성 참고

참고일: 2026-11-22

## 참고한 서비스

- [Collabstr](https://collabstr.com/): 첫 화면의 플랫폼 선택·키워드 검색, 크리에이터 탐색 진입점, 브랜드와 크리에이터의 진입 경로를 참고했습니다. 공개 페이지 내용으로 구조를 확인했으며, 로컬 브라우저의 직접 접근은 자동화 방지 화면으로 제한됐습니다.
- [리뷰노트](https://www.reviewnote.co.kr/): 국내 캠페인 서비스의 검색, 캠페인 이미지 카드, 플랫폼과 모집 정보 구성을 참고했습니다. 공개 페이지와 브라우저 화면을 확인했습니다.

두 서비스의 문구·실적·후기·고객 로고·프로필 데이터를 가져오지 않았습니다. Admasker의 카피와 레이아웃은 자체 작성했고, 기존 저장소의 사진·가상 브랜드 에셋을 사용했습니다.

## Admasker에 적용한 구성

1. 광고주/크리에이터 역할 선택에 따라 첫 화면의 문구·검색 대상·시작 경로가 바뀝니다.
2. 플랫폼과 키워드 검색, 분야별 바로가기가 기존 `/creators` 또는 `/campaigns`의 실제 필터로 연결됩니다.
3. 공개 프로필과 모집 캠페인을 API에서 읽습니다. 데이터가 없을 때는 명시적인 예시를 표시하고, 캠페인 API 연결 실패도 구분합니다.
4. 브랜드/크리에이터별 가치와 이용 방법을 나누고 실제 등록·탐색 경로로 연결합니다.
5. 영상 PPL은 하단 차별 기능으로 소개합니다. 제품 배치 시안과 실제 AI 재생성 결과를 혼동하지 않도록 표시했습니다.
6. 랜딩에만 밝은 테마를 적용하고 라임 브랜드 색을 유지합니다. 스튜디오와 워크스페이스의 기존 테마는 유지합니다.

실제 등록 프로필에는 콘셉트 사진을 붙이지 않고 이름 이니셜을 사용합니다. 예시에는 실제 회원 수·후기·선정률 같은 성과를 표시하지 않습니다.
